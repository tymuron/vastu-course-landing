# Васту-дизайн — лендинг курса Анны Ромео

Статическая страница: один `index.html` + `assets/`. Сборка не нужна.

Локально: `npx http-server . -p 8791 -c-1`

## Что править
Даты и приём заявок — объект `CFG` внизу `index.html`:
`startDate`, `earlyDeadline` (сейчас `null` → «дата уточняется», таймер скрыт),
`formEndpoint` (сейчас пусто → форма честно показывает ошибку, а не мнимый успех).

## Медиа
Видео первого экрана — `assets/media/hero-*.mp4` (AV1 + H.264, вертикальная петля 11 с).
Остальные слоты — плейсхолдеры с подписями, что за кадр и какого размера.

## Перед запуском обязательно
Реквизиты ИП/ИНН/ОГРНИП и ссылки на оферту и политику в подвале — заглушки.
Без них принимать оплату нельзя. Также заменить блоки с чипом «ЧЕРНОВИК».
