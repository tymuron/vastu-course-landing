# Васту-дизайн — лендинг курса Анны Ромео

Статическая страница: один `index.html` + `assets/`. Сборки нет, зависимостей нет.
Деплой — Render (`render.yaml`), статический сайт из ветки `main`.

Локально: `npx http-server . -p 8791 -c-1`

## Что править

Даты и ссылки на оплату — объект `CFG` внизу `index.html`:

* `startDate` — старт потока;
* `earlyDeadline` — до какого момента держится ранняя цена (таймер и все подписи
  по странице пересчитываются сами; поставьте `null` — вернётся «дата уточняется»,
  отсчёт спрячется);
* `pay.base` / `pay.pro` — товары на lava.top для тарифов «Основной»
  и «Наставничество». Кнопки «Занять место» ведут прямо туда, промежуточной
  формы бронирования нет.

## Шрифты

Cormorant и Manrope лежат в `assets/fonts/` — подключаются локально, без
запросов на сторонние сервера, кириллица и латиница разнесены по
`unicode-range`.

Макет нарисован на Vela Sans; её файлы не открытые, поэтому по умолчанию
рисует Manrope — он сделан на её основе, метрики почти совпадают.
Если файлы появятся: положить пять `VelaSans-*.woff2` в `assets/fonts/`
и снять комментарий с блока `@font-face` в начале `index.html`.

## Медиа

* Первый экран — `assets/media/hero-*.mp4` (вертикальная петля 11 с) плюс
  постер `hero-poster.webp`, который держит экран, пока грузится видео.
* Кейсы — `assets/cases/`, портфолио — `assets/portfolio/`, схемы Васту —
  `assets/diagrams/*.svg` (сгенерированы по секторам Анны, правятся как текст).
* Всё, кроме первого экрана, грузится лениво: до прокрутки страница тянет 0 КБ
  картинок, целиком — около 1,5 МБ.

## Чего ещё не хватает

Три слота ждут съёмку — они помечены прямо на странице подписью и нужным
размером:

* фото реальной квартиры «до» (2400×3200);
* скриншот платформы или кадр с прямого эфира (2400×1800);
* превью одного урока (1200×1200).

Чтобы поставить фото, замените блок `<div class="ph …">…</div>` на
`<img src="…" alt="" loading="lazy">` — размеры и обрезку класс возьмёт на себя.

## Контраст

Цвета подобраны так, чтобы весь текст держал WCAG AA (4,5:1, крупный — 3:1),
включая надписи поверх кадров. Если меняете `--gold-ink`, прозрачности
зачёркнутых цен или затемнение `.hero__scrim` / `.hero__scrim--end`, проверяйте
контраст заново — эти значения посчитаны, а не подобраны на глаз.
